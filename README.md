# 💼 Salary Prediction System

A complete **Machine Learning Salary Prediction System** built with Python, Scikit-learn, and Streamlit. The application predicts employee salaries based on factors such as job title, experience, education, skills, industry, company size, and location.

## 🚀 Features

* 📊 Dataset preview and analysis
* 🧹 Missing value handling
* 🔠 Label & One-Hot Encoding
* ⚖️ Feature scaling with StandardScaler
* 🤖 Linear Regression & Random Forest models
* 📈 MAE, MSE, RMSE & R² evaluation
* 📉 Actual vs Predicted visualization
* 🎯 Interactive salary prediction form
* 💾 Model saving with Joblib

## 🛠️ Technologies

**Python | Pandas | Scikit-learn | Matplotlib | Streamlit | Joblib**

## 🧠 ML Workflow

**Data → Cleaning → Encoding → Scaling → Model Training → Evaluation → Prediction → Streamlit Deployment**

## ▶️ Run the Project

```bash
pip install streamlit pandas scikit-learn matplotlib joblib
streamlit run salarry_prediction.py
```

Then open `http://localhost:8501` in your browser.
